# Journey prototype: Renovation, hands on (Nov 24 2026)

Each trail stop is a bench where you do the step with your fingers; every gesture writes progress back.

- Plan: drag/turn the kitchen island; live aisle clearances vs the 42″ rule from the saved link; save as Floor plan v4.
- Quotes: balance scale; ask Ridge for a quote, drop quotes on the pans, add Marco's electrical to the quote that excludes it; pick one → task done.
- Demolition: four blocker bricks (insurance, haul-away, permit, utilities); mark each done to knock it out; wall collapses; fling rubble.
- Build: drag panels into bays in order; electrical locked until inspection is booked.
- Finish: paint walls with a finger (inspiration colours), drag furniture in, open the tile crate; save finish picks.

Uses `lib/` and `models.js` from ../journey-3d-renovation (copy them in to run locally). Ridge, Marco and utilities numbers are sample data.
